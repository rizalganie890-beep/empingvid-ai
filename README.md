# EmpingVid AI

Frontend-first SaaS prototype for an AI video generator.

## Current phase
- Complete landing/marketing flow
- Login/register UI
- Pricing: Free / Plus / Pro / Max
- Dashboard and app navigation
- AI Video Generator marked **Coming Soon**
- Video library + detail route
- Templates
- Generation history
- Billing & credits
- Referrals
- Settings
- Testimonials, FAQ, Help
- About, Contact, Privacy, Terms
- EmpingVid AI logo SVG

## Deferred intentionally
Real authentication, PostgreSQL, payment gateway, credit ledger, queue, GPU/VM workers, storage/CDN, and production human-review tooling will be connected after the frontend flow is approved.

## Run locally
`npm install`

`npm run dev`
